Это эмуляция viewport/touch в Linux, **не проверка на физическом iPhone**.
Использованы Chromium 156.0.8078.79 и Playwright 1.56.1 с WebKit 26.0 / build 2215.
WebKit запущен с пользовательскими копиями недостающих Linux-библиотек, поскольку
в сессии нет root-доступа. Проверка системного реестра зависимостей Playwright
отключена (`PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1`), сам браузер реально
запускался и исполнял сценарии. Ошибки JavaScript не подавлялись.

Все запросы тестовых страниц перехватываются и обслуживаются локальными HTML-
фикстурами. Реальные CMP и сайты не обходились. Проверены сами ресурсные JS;
скрипты PageShield берутся из Swift-литералов строгим декодером, а не копируются
в отдельную тестовую реализацию.

## Что покрывает браузерный набор

- Явные отказы и выбор необходимых cookie, русские/английские подписи,
  неоднозначные кнопки без нажатия, конфликтующие подписи и подменённый CMP ID.
- Скрытые, прозрачные, отключённые и inert-кнопки; поздние баннеры; открытый
  Shadow DOM, удаление/возвращение shadow root, встроенный фрейм.
- Повторная инъекция, лимит действий, отсутствие поддельных cookie/localStorage,
  остановка наблюдателей и отложенной работы.
- Светлые и нативно тёмные поверхности, inline `!important`, полупрозрачные панели,
  oklch / sRGB / display-p3, динамическое содержимое, CSP со `style-src 'none'`.
- Отсутствие инверсии и переписывания тестовых img/video/canvas/SVG,
  сохранение редактируемых областей, восстановление стилей и последующих изменений сайта.
- Отзывчивость при обработке 4 000 элементов с обеими новыми функциями,
  остановка/повторное включение темы и событие восстановления закэшированной страницы.
- Все 8 существующих scriptlet, JSON.parse/Response.json, динамические атрибуты,
  классы, обработчики/таймеры, procedural `:has-text`, `:upward`, вложенный `:has`,
  ограничение правил по хосту и реальная прокрутка после скрытой cookie-стены.

## Исправления и сохранение данных

Из прежней проверки сохранено исправление `page-shield.py`: пять повреждённых
входных правил воспроизводимо обрывали исходный скрипт. Теперь они пропускаются,
а следующие правила продолжают обрабатываться; все текущие данные PageShield
проходят повторное преобразование без изменений.

Режим скрытия cookie-стены больше не нажимает кнопки согласия: явный отказ
принадлежит отдельной автоматике. В необходимом режиме скрытие отключено;
сайтовое исключение оставляет ручной выбор. JS-выключатель приостанавливает новые
функции. Обновление скриптов сохраняет скрипты других возможностей.

Новые настройки Codable имеют значения по умолчанию для старых файлов.
Для iOS подготовлены тесты миграции, round-trip, приватных исключений,
идемпотентности инъекции, доменной области cookie и упаковки локализации.
**Они не исполнялись в Linux.**

## Что остаётся непроверенным или заблокированным

- XcodeGen generation, Swift compiler/type checks, Debug/Release build и **182
  объявления Swift-тестов** не запускались: в среде нет macOS, Xcode и iOS Simulator.
- Нативный интерфейс, cookie-store API, реальная изоляция WKContentWorld,
  привязка callback к WKFrameInfo, сохранение настроек на устройстве и работа
  CloudKit требуют запуска на Apple SDK/устройстве. Браузерный event-тест моста
  не заменяет проверку нативного back/forward cache.
- Реальные CMP, визуальная совместимость всех сайтов, батарея и Apple-подпись
  не проверены. У тёмной темы есть эвристики и бюджет обработки; закрытый Shadow DOM
  не обслуживается. Неизвестные баннеры оставляются вручную.
- Apple Team / App IDs / CloudKit container не зарегистрированы в этой сессии.
  Подписанный IPA, установка на iPhone и собственный TestFlight не созданы.
- Удалённый форк не создан: GitHub API ранее вернул `403 Resource not accessible
  by integration`; повторная проверка `yoyovich/sail` не нашла доступного репозитория.
  GitHub Actions здесь не запускались — workflow подготовлены в исходниках.

[План ручной проверки](MANUAL_TESTS.md) и [инструкции сборки](FORK.md) включены.
Для повторения доступных проверок: `iOS/scripts/verify.sh --web`.
На настроенном Mac полный набор: `iOS/scripts/verify.sh --all`.
