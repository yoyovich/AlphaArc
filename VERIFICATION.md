## Подтверждённый дефект и исправление

В исходном `page-shield.py` пять случаев приводили к аварийному завершению:
пустой scriptlet, незакрытая кавычка, незакрытый вызов, style-правило без `{`,
незакрытый аргумент CSS pseudo-class. Ошибка воспроизведена тестом против
неизменённого upstream-скрипта: все пять сценариев завершились исключениями.

После исправления неподдерживаемое/повреждённое правило пропускается, обработка
последующих правил продолжается. Тесты проверяют наличие следующего корректного
правила, канонизацию scriptlet aliases, экранированные кавычки, CSS,
procedural selectors и сохранение всех текущих данных PageShield.
Это не заявление о полном покрытии всей грамматики фильтров.

## Подготовка форка

Конфигурация `iOS/fork.yml` дополняет исходную, а не заменяет её:
`com.yoyovich.sail`, `com.yoyovich.sail.tests`, `iCloud.com.yoyovich.sail`.
Entitlements используют build setting, CloudKit выбирает контейнер приложения.
Данные официального Mac-клиента автоматически в собственный контейнер не переносятся.

Проверка метаданных релиза теперь допускает bundle ID форка и явный override.
Её тесты используют настоящие plist-фикстуры и заглушки Apple CLI: проверены
валидный ID, ошибочный ID, override, ошибочные version/build и отсутствие privacy manifest.
Подпись, provisioning и права Apple этим не проверяются.

Скрипт архивирования проверяет наличие IPA после экспорта и не разбирает вывод `ls`.
Генерируемые проект, Info.plist, build artifacts и загруженные фильтры игнорируются Git.
CI настроен для main, `fork/**`, pull requests и ручного запуска.
Release workflow не включён для форка: ему нужны свои App Store Connect и TestFlight.

## Что не выполнено

- XcodeGen generation, сборка Debug/Release, Swift compiler checks и **170 объявлений
  тестов Swift** не запускались: отсутствуют macOS, Xcode и iOS Simulator.
- Интерфейс, жесты, WebKit, перевод, Reader, скачивания, разрешения сайтов,
  приватность на работающем устройстве и расход батареи не проверены в действии.
  Код приватных сессий и сохранения просмотрен, но это не заменяет runtime-тесты.
- CloudKit container/App IDs не зарегистрированы и Apple credentials не настроены.
- Подписанный IPA и TestFlight-сборка не созданы.
- Удалённый форк и GitHub CI не запускались. Попытка создать форк получила
  GitHub API `403 Resource not accessible by integration`.
- Идеи из предыдущих чатов не восстановлены; пользовательские функции по ним не реализованы.

## Воспроизведение

Из корня репозитория, с Python 3, Node.js, ShellCheck и actionlint:

```sh
iOS/scripts/verify.sh
```

Скрипт возвращает ошибку при неуспешной проверке или отсутствии lint-инструмента;
он явно помечает проверки iOS как пропущенные. На настроенном Mac:

```sh
iOS/scripts/verify.sh --ios
```

Инструкции по установке инструментов, Apple signing и публикации ветки — в [FORK.md](FORK.md).
